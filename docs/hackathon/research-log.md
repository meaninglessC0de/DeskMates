## 2026-11-14 (night): Synthesia access through LiveKit, and avatar ids
- **LiveKit Inference does NOT offer Synthesia on our LiveKit project.** A safe probe of the gateway (`POST https://agent-gateway.livekit.cloud/v1/avatar/sessions`, using the project's LiveKit key, with an invalid avatar id so no session could start or bill) answered HTTP 400 `unknown avatar provider "synthesia"`, hint `configured providers: lemonslice`. - The Synthesia plugin (`livekit-plugins-synthesia` 1.8.12) requires `SYNTHESIA_API_KEY` and calls `developers.synthesia.io` with it (`plugins/synthesia/avatar.py`). Never put the LiveKit key in that variable: it would be sent to a third party and fail. `verified` by reading source.
- LiveKit Inference avatars are the pattern the user's sponsor note probably meant ("the gateway creates the provider session with LiveKit's wholesale key", no provider key needed), but only for providers the gateway lists (LemonSlice today). LemonSlice accepts `image_url`, so it can animate a custom face per employee. Not a Synthesia bounty entry. `verified` by reading source (`agents/inference/avatar.py`).
